# Σύνδεση του Claude με το Bill Split

Με αυτή τη σύνδεση μιλάς στο Claude και εκείνο κάνει για σένα ό,τι θα έκανες μέσα στην εφαρμογή:
καταχωρεί έξοδα, σου λέει ποιος χρωστάει σε ποιον, γράφει εξοφλήσεις, ψάχνει παλιά έξοδα και σου
δίνει σύνολα ανά μήνα και κατηγορία.

Η ρύθμιση γίνεται μία φορά και θέλει περίπου 5 λεπτά.

## Τι χρειάζεσαι

- Λογαριασμό στο Bill Split: <https://bills.ninblack.com>
- **Claude Code** (τερματικό ή επέκταση VS Code) ή **Claude Desktop**

Η σύνδεση δεν δουλεύει ακόμη από το claude.ai στον browser ούτε από την εφαρμογή Claude στο κινητό.

## Βήμα 1: Φτιάξε το προσωπικό σου token

Το token είναι ένα κλειδί που δείχνει στο Bill Split ότι το Claude ενεργεί για λογαριασμό σου. Δεν
δίνεις ποτέ στο Claude τον κωδικό σου.

1. Άνοιξε το Bill Split και πήγαινε **Προφίλ → Σύνδεση με Claude**.
2. Γράψε ένα όνομα για να θυμάσαι πού το έβαλες, π.χ. «Claude στο laptop».
3. Διάλεξε τι επιτρέπεται:
   - **Ανάγνωση και αλλαγές**: το Claude βλέπει και γράφει.
   - **Μόνο ανάγνωση**: το Claude βλέπει έξοδα και υπόλοιπα αλλά δεν αλλάζει τίποτα.
4. Διάλεξε διάρκεια (30 ημέρες, 90 ημέρες ή 1 χρόνος). Όταν λήξει, φτιάχνεις καινούργιο.
5. Πάτα **Δημιουργία token** και αντίγραψέ το αμέσως. Ξεκινά με `bst_` και εμφανίζεται **μόνο μία φορά**.

## Βήμα 2: Πρόσθεσέ το στο Claude

### Claude Code

Μετά τη δημιουργία του token, το κουμπί **Αντιγραφή εντολής για Claude Code** σου δίνει έτοιμη την εντολή.
Επικόλλησέ τη σε ένα τερματικό. Αν θες να τη γράψεις μόνος σου, είναι αυτή, με το δικό σου token στη θέση
του `bst_...`:

```bash
claude mcp add --transport http --scope user bill-split https://bills.ninblack.com/api/mcp --header "x-api-key: bst_..."
```

Το `--scope user` κάνει τη σύνδεση διαθέσιμη σε όλους τους φακέλους σου, όχι μόνο στον τρέχοντα.

Έλεγχος: τρέξε `claude mcp list`. Το `bill-split` πρέπει να εμφανίζεται ως συνδεδεμένο. Μέσα στο Claude
Code το ίδιο φαίνεται με `/mcp`.

### Claude Desktop

Το Claude Desktop χρειάζεται ένα μικρό βοηθητικό πρόγραμμα (`mcp-remote`) που τρέχει με το
[Node.js](https://nodejs.org) (έκδοση 18 ή νεότερη). Εγκατάστησε πρώτα το Node.js αν δεν το έχεις.

1. Στο Claude Desktop: **Settings → Developer → Edit Config**. Ανοίγει το αρχείο `claude_desktop_config.json`.
2. Πρόσθεσε το παρακάτω, με το δικό σου token στη θέση του `bst_...`. Αν το αρχείο έχει ήδη ενότητα
   `mcpServers`, βάλε μέσα της μόνο το κομμάτι `"bill-split": { ... }`.

```json
{
  "mcpServers": {
    "bill-split": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://bills.ninblack.com/api/mcp",
        "--header",
        "x-api-key:${BILL_SPLIT_KEY}"
      ],
      "env": {
        "BILL_SPLIT_KEY": "bst_..."
      }
    }
  }
}
```

3. Κλείσε εντελώς το Claude Desktop και άνοιξέ το ξανά. Το `bill-split` εμφανίζεται στα εργαλεία της
   συνομιλίας.

## Βήμα 3: Δοκίμασέ το

Γράψε στο Claude κάτι σαν:

- «Πόσα χρωστάω στο Σπίτι;»
- «Γράψε στο Σπίτι σούπερ μάρκετ 47,30 που πλήρωσα εγώ σήμερα.»
- «Βάλε 120 ευρώ ρεύμα που πλήρωσε η Μαρία, 70/30.»
- «Πόσα ξοδέψαμε σε φαγητό τον Οκτώβριο και πόσα τον Σεπτέμβριο;»
- «Βρες το έξοδο για το βενζινάδικο της περασμένης εβδομάδας και κάν' το 55.»
- «Έδωσα 80 ευρώ στον Γιάννη, γράψ' το ως εξόφληση.»
- «Τι πληρωμές χρειάζονται για να είμαστε όλοι πάτσι;»

## Τι μπορεί να κάνει το Claude

| Περιοχή | Βλέπει | Αλλάζει (μόνο με token «Ανάγνωση και αλλαγές») |
|---|---|---|
| Ομάδες | Τις ομάδες σου με το υπόλοιπό σου σε καθεμία, μέλη, κανόνα διαμοιρασμού | Νέα ομάδα, ρυθμίσεις, ποσοστά, διαγραφή, συμμετοχή με κωδικό |
| Μέλη | Ονόματα και email των μελών των ομάδων σου | Προσθήκη με email, αφαίρεση, νέος κωδικός πρόσκλησης |
| Έξοδα | Λίστα με αναζήτηση, μήνα και κατηγορίες, μερίδια ανά μέλος | Νέο έξοδο, διόρθωση, διαγραφή |
| Στατιστικά | Σύνολα ανά μήνα, ανά κατηγορία και ανά μέλος | |
| Υπόλοιπα | Ποιος χρωστάει σε ποιον, προτεινόμενες πληρωμές | |
| Εξοφλήσεις | Ιστορικό πληρωμών | Καταγραφή, διαγραφή |
| Αλλαγές χρεών | Διορθώσεις και μεταφορές | Διόρθωση χρέους, μεταφορά σε άλλη ομάδα, διαγραφή |
| Διαγραμμένα | Ό,τι έχει διαγραφεί | Επαναφορά |
| Λογαριασμός | Όνομα, email | Αλλαγή ονόματος, δοκιμαστική ειδοποίηση |

Αυτά γίνονται **μόνο μέσα από την εφαρμογή** και όχι από το Claude: η αλλαγή κωδικού, η δημιουργία ή
ανάκληση tokens, η ενεργοποίηση ειδοποιήσεων push σε μια συσκευή και η διαχείριση του ποιος έχει πρόσβαση
από το Internet.

## Ασφάλεια

Πώς προστατεύεται η σύνδεση:

- Η επικοινωνία είναι κρυπτογραφημένη (https) από το Claude μέχρι το Bill Split.
- Το Claude δεν μαθαίνει ποτέ τον κωδικό σου. Έχει μόνο το token.
- **Κάθε token βλέπει μόνο τα δικά του.** Το token ανήκει σε έναν λογαριασμό και φτάνει μόνο στις ομάδες
  στις οποίες είναι μέλος αυτός ο λογαριασμός. Ομάδες άλλων δεν εμφανίζονται και δεν αλλάζουν, ακόμη κι αν
  το Claude ζητήσει τον αριθμό τους. Ο έλεγχος γίνεται στο ίδιο σημείο που γίνεται και για την εφαρμογή.
- Το Bill Split δεν αποθηκεύει το ίδιο το token αλλά ένα μη αναστρέψιμο αποτύπωμά του. Γι' αυτό δεν μπορεί
  να σου το ξαναδείξει.
- Κάθε token λήγει μόνο του και ανακαλείται όποτε θες. Η ανάκληση ισχύει αμέσως.
- Πολλές λάθος προσπάθειες από την ίδια διεύθυνση μπλοκάρονται για 15 λεπτά.
- Κάθε ενέργεια του Claude καταγράφεται στο Bill Split (ποιο token, ποια ενέργεια, πότε).

Τι να προσέχεις εσύ:

- Φέρσου στο token όπως σε έναν κωδικό. Μην το στέλνεις σε μηνύματα ή email και μην το ανεβάζεις σε
  κοινόχρηστους φακέλους ή σε git.
- Χρησιμοποίησε **ένα token ανά συσκευή**. Αν χάσεις μια συσκευή, ανακαλείς μόνο το δικό της.
- Αν θες το Claude μόνο να σε ενημερώνει, διάλεξε **Μόνο ανάγνωση**.
- Ό,τι γράφει το Claude το βλέπουν και τα άλλα μέλη της ομάδας, και για κάθε νέο έξοδο παίρνουν ειδοποίηση.
  Το Claude έχει οδηγία να σου λέει τι πρόκειται να κάνει και να περιμένει το «ναι» σου πριν αλλάξει κάτι.
  Διάβασε το ποσό και την ομάδα πριν απαντήσεις.
- Τίποτα δεν χάνεται οριστικά: ό,τι διαγραφεί επαναφέρεται από τα «Διαγραμμένα» της εφαρμογής ή από το Claude.
- Αν υποψιαστείς ότι το token το είδε κάποιος άλλος: **Προφίλ → Σύνδεση με Claude → Ανάκληση** και φτιάξε
  καινούργιο.
- Στο **Προφίλ → Σύνδεση με Claude** βλέπεις πότε χρησιμοποιήθηκε τελευταία φορά κάθε token. Αν δεις χρήση
  που δεν έκανες εσύ, ανακάλεσέ το.

## Αν κάτι δεν δουλεύει

| Τι βλέπεις | Τι σημαίνει | Τι κάνεις |
|---|---|---|
| `401` ή «Το token δεν είναι έγκυρο, έχει λήξει ή έχει ανακληθεί» | Το token γράφτηκε λάθος, έληξε ή ανακλήθηκε | Φτιάξε νέο token και ξαναπρόσθεσε τη σύνδεση |
| «This token is read-only» | Το token είναι «Μόνο ανάγνωση» | Φτιάξε token «Ανάγνωση και αλλαγές» |
| «Δεν είστε μέλος αυτής της ομάδας» | Η ομάδα δεν είναι δική σου | Ζήτησε από ένα μέλος της να σε προσθέσει |
| `429` | Πολλές λάθος προσπάθειες ή πάρα πολλές κλήσεις | Περίμενε 15 λεπτά και έλεγξε το token |
| Σελίδα σύνδεσης Cloudflare αντί για απάντηση | Ο διαχειριστής δεν έχει ανοίξει ακόμη τη σύνδεση για το Claude | Ζήτησέ του να τρέξει τη ρύθμιση «Claude» του README |
| Το `bill-split` δεν εμφανίζεται στο Claude Desktop | Το αρχείο ρυθμίσεων έχει λάθος ή λείπει το Node.js | Έλεγξε τα κόμματα και τις αγκύλες του JSON, εγκατάστησε το Node.js, κάνε επανεκκίνηση |

Για να αφαιρέσεις τη σύνδεση από το Claude Code: `claude mcp remove bill-split`. Μετά ανακάλεσε και το
token από την εφαρμογή.
